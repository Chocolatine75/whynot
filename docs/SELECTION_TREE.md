# Demo: natural selection of ads (who does what, and the data contract)

Decided Oct 31 (Matteo + Tom): the demo is on a **Meta product** ("Muse from Meta", App Store id 6760173601), labelled
"concept ad made by whynot, not an official Meta ad". The system is real; the **performance data used for selection
is simulated** and labelled as such everywhere. VietBuddy is out of the demo.

Demo story (3 minutes):
1. **Every ad type** the system makes (gallery: one ad per viral format, the classic ad, the static ad).
2. **A full campaign on Muse**: research → strategy from real reviews → ads → daily loop.
3. **Natural selection**: the tree of ads over 3 simulated weeks, nodes sized by views, losers cut, winners' children
   branching; next to it, the same world run with **random ideas (no learning)**. The curve "views / conversions per €"
   rises with whynot and stays flat at random.

## The contract: `outputs/runs/<run>/agency-sim/selection.json`

Tom can build the page now with a hand-written file of this shape; ours will match it.

```json
{
  "simulated": true,
  "label": "Simulated campaign: performance numbers are generated by a model, not real Meta results",
  "app": {"name": "Muse from Meta", "icon": "assets/icon.png"},
  "days": 21,
  "budget_per_ad_eur": 5.0,
  "policies": {
    "whynot": {
      "nodes": [
        {"id": "day-2026-11-01-1-...", "day": 1, "parent": null, "format": "pov", "persona": "...", "angle": "...",
         "hook": "pov crashing at my moms", "status": "live|paused|failed|proposed", "why": "explore: ...",
         "impressions": 12000, "clicks": 140, "conversions": 11, "spend_eur": 35.0, "cpa_eur": 3.18,
         "video": "videos/day-2026-11-01-1-....mp4", "poster": "videos/....poster.jpg", "paused_day": 7}
      ],
      "timeline": [
        {"day": 1, "live": 2, "spend_eur": 10.0, "impressions": 3400, "conversions": 2,
         "views_per_eur": 340.0, "conversions_per_100_eur": 20.0}
      ]
    },
    "random": {"nodes": [], "timeline": []}
  },
  "truth": {"best_format": "pov", "best_angle": "...", "best_persona": "..."},
  "summary": {"whynot_conversions_per_100_eur_last_week": 0.0, "random_conversions_per_100_eur_last_week": 0.0}
}
```

- `parent`: the ad whose message this one re-used (exploit); `null` for explored ideas. Draw edges parent → child.
- `video` / `poster`: present only for ads rendered as video (the ones shown on screen); others are scripts only.
- `truth`: the hidden best combination of the simulated world, shown at the end ("whynot found it on day N").
- Every screen that shows these numbers carries `label`.
